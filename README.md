# 🔍  dork generator
Dork Gen DorkMaster


**DorkGen** is a script for generating keyword combinations used in web page URLs.  
It is designed to assist with **web scraping**, **penetration testing**, **bug bounty**, and **security research** by quickly creating customized dork lists based on user-defined variables.

---

## ✨ Features

- 🚀 **Fast generation** of URL keyword combinations  
- 🧩 **Customizable inputs** – define your own variables, extensions, and operators  
- 📂 **Config file support** – load default values from configuration files for persistent preferences  
- 📈 **Extensive dork library** – includes many new and improved dorks for better results  
- 🛠️ **Lightweight & modular** – easy to extend or integrate into other tools
